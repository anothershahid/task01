# task01

Responsive first section of **The Blog** Figma design, implemented with plain human-written HTML, CSS, and JavaScript.

## Run locally

No build step is required. Clone the repository and open `index.html` in a browser, or serve the folder with any static server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Included

- Responsive desktop, tablet, and mobile layouts
- Semantic blog structure and accessible navigation
- Mobile navigation menu
- Light/dark mode toggle
- Responsive featured post, recent-post list, and all-posts grid
- Image crops and spacing tuned to match the supplied Figma reference

The image URLs are loaded from Unsplash and can be replaced with exported Figma assets in the same markup without changing the layout.
